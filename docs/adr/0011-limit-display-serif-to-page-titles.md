# 衬线展示字体只用于品牌与页面主标题

Claude 视觉规格的衬线展示字体能够提供品牌辨识度，但全量用于数据密集的租户与平台管理界面会降低扫描效率。前端仅在品牌名称、每个页面唯一的主标题和低密度认证页面的关键展示文案中使用 `font-display`，并将产品页面主标题控制在 28-36px；二级标题、Card、Navbar、表单、按钮和操作区使用 sans，结构化数字与代码信息按语义使用 mono。

本决策保留 ADR 0003 的字体 token 与 fallback 链，但不把 `claude-DESIGN.md` 面向营销页面的 48-64px 展示标题直接套用到产品控制台。
