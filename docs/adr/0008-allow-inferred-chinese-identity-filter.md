# 允许推断的华人身份作为可执行条件

首期可执行条件目录保留检索底座的 `chinese_identity` 字段，允许职位需求按国内华人、海外华人或外国人筛选。该值由姓名和国家信息启发式推断，并非本人声明，也不能解释为国籍、民族或血统；接受误判可能直接影响候选人召回，是为延续冻结 PRD 中既定筛选能力而作出的明确产品取舍，而不是对该字段准确性或合规性的确认。

面向租户用户的职位需求、匹配结果和解释统一显示“华人身份”，不标注该值来自推断，不展示推断依据，也不提示可能误判。这是有意选择的信息展示边界；它不改变内部领域定义和数据来源事实，也不替代面向数据主体的告知、同意、自动化决策透明度或其他上线合规判断。

开发阶段不以合规性或法律风险评估作为该能力的阻塞条件，先按上述产品语义完成实现与技术验收。生产上线所需的合规判断不在本次设计范围内，既不作为当前门禁，也不视为已经完成或获得批准。
