# 本仓库仅以服务身份消费版本化检索底座契约

商业产品不实现检索存储，也不直连检索底座的数据库或索引。本仓库只交付消费者侧：检索契约版本、服务端客户端、假检索底座，以及可在 CI 运行的契约测试。真实人物与论文检索仍由独立的检索底座提供。相较于在本单体中转发 OpenSearch、或把契约实现放到检索底座仓库后再阻塞本仓，这一边界让 `#13` 之后的本地人才、搜索和匹配可以在假底座上验收，同时避免商业模块拼 DSL。

检索底座契约只认规范人物，不认本产品的本地人才。成功响应携带当前数据版本；检索底座只服务当前已发布索引，不能按历史数据版本回查。历史匹配与报告的解释依赖本产品在读取当时落下的快照。相较于要求底座保留全部历史索引，或把数据版本与快照标识混成一个可回查键，这一选择与现有「一份当前索引」的底座能力一致，也避免用新证据解释旧结论。

人才检索只接受硬条件与研究主题查询，返回检索命中：当前字段、命中论文与语义相关性信号，不含完整联系方式，也不计算匹配算法版本下的总分。自然语言原句不进入检索底座；底座现有的自然语言找专家接口仍是其内部验证工具。人物证据是当前数据版本下的人档论文与结构化字段出处，不依赖某次检索，同样不含完整联系方式。批量读取允许当前缺失下的部分成功：返回找得到的规范人物并列出当前数据版本中不存在的标识，底座不区分从未存在与业已消失。

检索契约版本独立于数据版本和职位需求 Schema 版本：前者冻结读取形状与当前缺失的表达，并声明可执行的 Schema 版本；数据刷新不构成契约不兼容；Schema 若引入底座尚不能执行的字段，必须等待检索契约升级。只有本产品 API 与 Worker 以服务身份调用检索底座；租户成员、浏览器和平台管理员的个人身份不能直连。完整联系方式、本地人才映射、自然语言搜索计量和匹配评分不在本契约内。
