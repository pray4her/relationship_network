# 检索契约允许仅硬条件召回，命中携带论文摘要（supersede ADR 0025 相应条款）

人才检索请求在硬条件与研究主题查询上改为「至少一项非空」：二者都空是无效查询；仅有研究主题时仍做语义召回；仅有硬条件时只做结构化过滤、不走向量。自然语言原句仍不得进入检索底座。相较于继续要求非空研究主题（会挡住独立自然语言搜索中的纯筛选），或把搜索原句填进研究主题查询（等于把自然语言送进底座，与 ADR 0025 的边界冲突），这一选择让结构化过滤成为一等召回，而不假装比较了研究相关性。

无研究主题时检索命中不含语义相关性信号，默认按 h-index 降序、同分按规范人物 ID；有研究主题时仍含语义分并按其降序。排序键不是检索契约的一部分，本产品对已返回命中做展示层改排。相较于把语义分填 0 或把排序键下放到检索底座，缺省语义分避免用假相关性解释纯筛选结果，展示层排序也不强迫底座理解本产品的结果表。

检索命中必须自带命中论文摘要（标题、年份、venue，可选 snippet），而不只是论文 ID。人物证据仍是按规范人物、按当前数据版本的独立读取，不依赖某次检索。相较于命中后批量拉人物证据补标题（最多 500 次额外读取，且会用新证据解释旧命中），命中当时带上摘要才能冻进本产品的搜索命中快照。

**ADR 0025 中被 supersede 的条款**：人才检索必须带非空研究主题查询；空硬条件仅在有研究主题时有效；检索命中必须含语义分并按其降序；命中论文仅为 ID。**仍然有效的条款**：本仓库只消费契约、不实现检索存储；契约只认规范人物与当前数据版本；原句、偏好条件、未支持条件不得进入检索底座；不含完整联系方式与匹配总分；服务身份调用；完整联系方式、本地人才映射、搜索计量和匹配评分不在本契约内。

## Considered Options

- **保持主题必填**：被否。独立自然语言搜索允许没有研究方向的硬条件查询。
- **用搜索原句冒充研究主题查询**：被否。ADR 0025 禁止原句进入检索底座，语义分也会排在非研究文本上。
- **无主题时语义分一律为 0**：被否。0 分假装比过相关性。
- **命中只带论文 ID，展示时补当前人物证据**：被否。无法冻结当时标题，也打穿 P95。
