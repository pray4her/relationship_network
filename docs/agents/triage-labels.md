# Triage Labels

The engineering skills use five canonical triage roles. The repository uses the same strings as its GitHub label names.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue |
| `needs-info` | `needs-info` | The issue is waiting for more information |
| `ready-for-agent` | `ready-for-agent` | The issue is fully specified and ready for an autonomous agent |
| `ready-for-human` | `ready-for-human` | The issue requires human implementation or coordination |
| `wontfix` | `wontfix` | The issue will not be actioned |

When a skill mentions a canonical role, apply the corresponding GitHub label from this table. Do not create synonymous duplicate labels.
