Navigation item state matrix

Forced with .is-* classes for the static showcase; live items use the pseudo-classes and aria-current.

Default Hover Pressed Current Focus-visible Current + focus Disabled Quiet Quiet hover

Hover fills --accent; pressed holds the --surface-cream-strong active-tab band; current is the semantic selection pair — --selected-bg fill with a --selected-border bottom edge at --border-width-strong — driven by aria-current="page", never a parallel class. Focus is the shared --ring-focus ring (stacking under the edge when current); disabled dims at --opacity-disabled; quiet items run the --muted-foreground hover/active pairs.
