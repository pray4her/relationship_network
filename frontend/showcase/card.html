Component

Card

A composable surface container — five surface variants, seven optional parts, zero business content. Whole-card interactivity uses pattern A (the root IS the <a>, content stays non-interactive); cards with buttons use pattern B (inert root, interactivity lives in .card__actions). Static state classes (.is-hover, .is-active, .is-focus-visible, .is-disabled) mirror the real pseudo-classes so this page can render them without interaction. Every value is a tokens.css reference.

Variants

default — --card fill, no border (feature-card recipe)

Default

Cream fill one step below the canvas

The workhorse surface for feature and content groupings.

outlined — --background + --border hairline

Outlined

Canvas fill with a hairline border

For dense lists where a filled card would feel heavy.

elevated — --background + --shadow-subtle (used rarely)

Elevated

The one sanctioned shadow

Reserved for moments that must float above the canvas.

selected — --selected-bg + --selected-border hairline

Selected

The emphasized-band token speaks

Marks the chosen item in pickers and comparison grids.

Selection resolves to the dedicated --selected-bg / --selected-border tokens — reported by this component as a gap, now shipped in tokens.css. All variants keep a --border-width border (transparent when unused) so they stay the same outer size in a grid.
