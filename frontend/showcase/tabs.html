Tabs

Two variants (underline, contained), three sizes, six states — every value a tokens.css reference. Static state classes (.is-hover, .is-active, .is-focus-visible) mirror the real pseudo-classes; selection is styled from aria-selected="true", never a parallel class. The live demos below implement the full WAI-ARIA tabs pattern: roving tabindex, Arrow/Home/End keys, disabled tabs skipped.

Underline × states

default hover pressed focus-visible disabled selected underline

Quiet rail (--border-soft), muted labels that darken through the --muted-foreground hover/active pair, and a --primary indicator at --border-width-strong for the selected tab. The indicator is an inset shadow, so the focus ring stacks on top without moving it.

Contained × states

default hover pressed focus-visible disabled selected contained

The design spec's "Category tabs" recipe: transparent at rest, --accent on hover ("hover/tab-active bg"), --surface-cream-strong when selected ("active tabs"). Selection is one tone deeper than hover, so the two states never collide.

Sizes

Heights ride the shared control ladder (--control-height-sm / --control-height / --control-height-lg); text steps --text-caption → --text-nav-link → --text-title-sm; inline padding steps --space-3 → --tab-padding-inline → --space-6.

Content configurations

Icons size to --icon-size-sm (--icon-size-md on lg tabs) with --stroke-width-icon paths and inherit currentColor, so they follow every tab state. Badges are composed unmodified from badge.css; the --space-2 gap does the spacing.

Overflow — narrow container

Tabs never wrap or squash: the list scrolls horizontally and keeps every tab at full width. The selected tab scrolls into view when reached by keyboard.

The tablist is overflow-x: auto with --ring-width of breathing room (negative-margin compensated) so the focus ring is never clipped by the scroller.
