Table

A data table with optional header, footer, sortable columns, row selection, and row actions — built entirely from tokens: the header band is --surface-soft in caption-up text, body rows are --text-body-md over quiet --border-soft dividers, selection resolves to the --selected-* pair, and every focus state uses the shared --ring-focus recipe. Sorting is a native button inside <th aria-sort> — Tab focuses, Enter/Space toggles, and direction is announced by the attribute itself.
