Link

Four variants, three sizes, six states — always a real <a href>, never a button pretending to navigate. Static state classes (.is-hover, .is-active, .is-focus-visible) mirror the pseudo-classes so this page can render them without interaction. Disabled links drop the href entirely: an anchor without one is inert.

Inline links

When a subscription lapses the tenant turns read-only and the write gate explains why instead of failing silently. Every billable action lands in the usage ledger under an idempotency key — see the audit trail for the append-only record. Removing a member is permanent; read the data-retention policy before you confirm.

Inline links inherit the surrounding text metrics — the md size is the base and never sets its own font size, so a link inside body-md, body-sm, or a heading always matches its context.
