Button

Four variants, three sizes, six states — every value a tokens.css reference. Static state classes (.is-hover, .is-active, .is-focus-visible) mirror the real pseudo-classes so this page can render them without interaction. Loading buttons keep their dimensions, carry aria-busy="true", and are disabled so they cannot fire.

Loading preserves dimensions

rest → loading

Each loading button sits beside its resting twin: identical footprint. The disabled attribute blocks click, keyboard, and programmatic activation; aria-busy="true" tells assistive tech the control is processing.

Full width

.btn--full only sets width: 100% — a layout property, no token needed. Height and padding tokens are untouched; the loading spinner still centers.
