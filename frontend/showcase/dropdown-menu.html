DropdownMenu

The complete matrix in one preview: every item type — standard, icon + label, keyboard shortcut, checkbox, radio, group label, separator, submenu trigger, destructive — rendered across every interaction state without touching a pointer. The surface is --popover on --z-dropdown under --shadow-lift; highlighting is --accent; selection rides the reserved indicator slot in currentColor; destructive rows use the --destructive family; disabled rows drop to --opacity-disabled. All values are tokens.css references.

Highlighted = --accent fill (the system hover token, for hover AND keyboard focus — menu focus is programmatic, so the ring rides :focus, not :focus-visible). Selection never touches the surface: the reserved --icon-size-sm indicator slot shows a currentColor check (checkbox) or dot (radio). Destructive rows are --destructive text with the dedicated --destructive-hover / --destructive-active interaction tokens. Disabled rows drop to --opacity-disabled and are skipped by the keyboard layer.

Open with Enter or Space, then drive it entirely from the keyboard. Checkbox items toggle and keep the menu open; radio items select within their group; activating an action or a destructive row closes the menu and logs it below. Type a letter to jump to a matching item.

Keyboard navigation

KeyBehaviour
Enter / SpaceOn the trigger: opens the menu and focuses the first item. On an item: activates it.
↓ / ↑Move focus to the next / previous enabled item, wrapping at the ends.
Home / EndFocus the first / last enabled item of the open panel.
→On a submenu trigger: opens the branch and focuses its first item.
← / EscInside a submenu: closes it and returns focus to its trigger. Esc on the root closes the menu and refocuses the trigger.
TabCloses the menu; the tab order holds exactly one item per panel (roving tabindex).
a–zType-ahead: focus jumps to the next item whose label starts with the typed letters.

Open / close motion

The tooltip/popover lifecycle reused verbatim: enter over --duration-normal, exit over --duration-fast, both on --ease-standard, parked --space-1 toward the trigger while closed. Submenus travel the same curves horizontally. Under prefers-reduced-motion: reduce every transition is removed.

Scroll cap & narrow columns

Members

The panel caps at --menu-max-height (six rows) and scrolls; arrow-key focus lands each row in view. The column is --sidebar-width wide — the panel's min-width — and the long name wraps because items carry a min-height floor, not a fixed height.
