Component

Slider

A native <input type="range"> under appearance: none — Arrow keys step, PageUp/PageDown jump, Home/End hit the bounds, and the platform exposes role="slider" with aria-valuemin/max/now from the markup. Range mode stacks two native inputs so each thumb keeps its own keyboard control and ARIA. The fill percentages are dynamic state painted by a small controller; every color, size, and motion value is a token.

Keyboard is the native contract of type="range": Arrow keys move one step, PageUp/PageDown move a browser-defined large step, Home/End jump to min/max. The <output> has implicit role="status", so value changes are announced. Static-state cells are duplicates with tabindex="-1" so they never enter the tab order.

Inputs are click-through except on their thumbs, so either thumb can be grabbed where they overlap; Tab reaches both. The controller clamps the pair (lower ≤ upper) and paints the two fill stops on the wrapper.
