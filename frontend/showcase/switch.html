Component

Switch

A <button role="switch"> carrying aria-checked — Space/Enter fire the native button click, a three-line controller flips the attribute, and every visual state is styled from it. Track width is calc(track-height × 2) and the thumb's travel resolves to exactly one track height, so the checked position is derived from tokens, never written as a raw number.

States (md)

off — default

on

hover off — .is-hover mirrors :hover

hover on

active off — .is-active mirrors :active

active on

focus-visible — .is-focus-visible mirrors :focus-visible

disabled off

disabled on

loading off — disabled + aria-busy + .is-loading

loading on

live — hover, press, Tab, Space/Enter

Keyboard is the button's own contract: Tab moves focus (token ring appears), Space and Enter fire click — the controller below maps that onto aria-checked. The .is-* classes exist only so static pages like this one can render the pseudo-states.

Sizes

sm — track --switch-track-height-sm (16px)

md — track --switch-track-height-md (24px)

lg — track --switch-track-height-lg (32px)

Thumb diameter and travel distance re-derive from the size token — the on-position thumb stays flush against the track edge at every size.

Assemblies

switch only — aria-label carries the name

switch + label — wrapping <label>, click anywhere

switch + label + description

label + description, disabled

label + description, loading — text stays opaque
