Component

Checkbox

A native <input type="checkbox"> under appearance: none — Space toggles, Tab focuses, forms submit, nothing reimplemented. The check and the indeterminate dash are drawn from CSS borders in currentColor, so their color is always the --primary-foreground token, never an asset or a raw hex.

States (md)

unchecked

checked

indeterminate — set via JS, :indeterminate styled

hover / active / focus-visible — live: hover, press, Tab

disabled unchecked

disabled checked

error — [aria-invalid] drives the border

error checked

Keyboard is the native contract: Tab moves focus (token ring appears), Space toggles. Indeterminate clears to a definite state on the first toggle — the platform's own behavior, kept intact.

Sizes

sm — --checkbox-size-sm (16px)

md — --checkbox-size-md (18px)

lg — --checkbox-size-lg (20px)

Assemblies

checkbox only — aria-label carries the name

checkbox + label — wrapping <label>, click anywhere

checkbox + label + description

label + description, disabled
