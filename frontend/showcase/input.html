Component

Input

The field chrome lives on .input-wrap — a flex frame that owns border, ring, and every state — while the native .input stays borderless inside it. That is what lets icons, prefix/suffix text, and a clear button sit inside the frame. All examples are paired with the FormField component for labels, helpers, and validation messaging.

Types

Minimum 12 characters.

Sizes

sm — --control-height-sm, --text-body-sm

md — --control-height, --text-body-md

lg — --control-height-lg, --text-body-md

States

default + placeholder

filled — text already --foreground

hover / focus — interact: hover border --border-strong, focus ring coral

disabled — whole wrap at --opacity-disabled

readonly — bg --muted, still focusable & copyable

error — border --destructive

success — border --success

Focus-within drives the ring, so keyboard and mouse focus both announce. Error can also be driven purely by markup: :has(.input[aria-invalid="true"]) applies the same border without the .input-wrap--error class.
