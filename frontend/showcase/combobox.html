Component

Combobox

Three modes — single, searchable, clearable — on one anatomy: an Input-family control with a listbox popup. Filtering is pure behavior: the script hides non-matching options with the hidden attribute and never touches a style; the CSS never knows filtering happened. Keyboard: type to filter, ArrowDown/Up to move, Enter to commit, Escape to close (or clear, in clearable mode), Home/End keep their native caret behavior.
