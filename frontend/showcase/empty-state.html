Platform health

Chip system: first-use --info-soft / --info, no-results --surface-soft, no-data --card (one card tone deeper so the two neutrals stay distinguishable), error --destructive-soft / --destructive — the semantic error tokens appear only on the scenario that is actually an error. Titles read at --text-title-lg in --foreground; descriptions at --text-body-md in --muted-foreground so the title stays the loudest voice. Primary actions are .btn--primary; secondaries are .btn--secondary or a .link--standalone — both reused unmodified.

Media — icon chip, illustration, or none

The media slot is optional. The icon chip sizes to --avatar-size-xl with an --icon-size-lg glyph; an illustration is content-driven — the asset carries its own dimensions and the slot only centers it and passes the variant tint through currentColor; and copy-only is a valid, complete empty state.
