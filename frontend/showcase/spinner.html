Spinner

Indeterminate loader: a foreground arc rotating over a background track, every stroke, size, opacity, duration, and easing a tokens.css reference. All sizes and variants render in one preview so visual weight compares directly; the contexts — spinner only, spinner plus label, inline loader, button loading state, and the reduced-motion freeze — each get an explicit band, closing with the loader’s place in the system-wide loading hierarchy.

Loading state matrix — all sizes × variants

xs / sm / md / lg ride the icon-size ladder (12 / 16 / 18 / 24px); the stroke holds at --space-0-5 through md and steps one micro rung up (--space-0-75) at lg so the largest ring keeps its weight. Default and primary read on the canvas; inverse rides a --surface-dark band — the only surface its tokens support.

Stroke pairs: default arc --foreground on track --border; primary arc --primary on track --primary-disabled (the muted primary-hue cream); inverse arc --on-dark on track --surface-dark-elevated. Both strokes are opaque token colors — no raw alpha; opacity enters only through composed Button states.

Contexts — only, labelled, inline

Ring only: the wrapper is role="status" with an author-supplied aria-label when it communicates state, or aria-hidden when decorative. Ring plus label: the visible text is the accessible label and the wrapper is the live region. Inline loader: an xs ring dropped into running text at the copy’s baseline.

Button loading state

Two recipes, one hierarchy: the Button’s native .is-loading contract (its own .btn__spinner, same token recipe — --icon-size-sm ring at --space-0-5), and this component composed in the icon slot, aria-hidden, with the button text as the accessible name. Inverse on filled buttons, default on quiet ones; sm matches the native footprint, xs fits btn--sm. A disabled (unavailable, not busy) control shows the opacity token --opacity-disabled.

Busy ≠ unavailable: .is-loading keeps full opacity while a plain disabled drops to --opacity-disabled — the only opacity in the system, and it belongs to Button, not to the ring.

Reduced-motion treatment

Rotation is --duration-slow linear infinite — the longest duration token, linear because a continuous spin has no easing to speak of (Button and Skeleton derive their timings from the same token). Under prefers-reduced-motion: reduce the animation is removed and the ring holds as a static three-quarter arc; the label — visible or aria-label — keeps carrying the state. The .is-reduced twin renders that freeze statically.

Loading hierarchy — against the system

The spinner’s weight sits between Skeleton’s block-level shimmer and the copy-level inline ring: Skeleton owns whole regions, the labelled spinner owns a panel or a request, Button loading owns a single control, and the inline xs ring owns a phrase. Same token family throughout — --card shimmer, --duration-slow-derived timings, --ease-standard curves.
