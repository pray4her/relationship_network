Component

Textarea

The multi-line member of the Input family — same semantic field tokens for background, border, focus ring, and validation; the only structural difference is block padding and a token-derived minimum height. Sizes pair with a default rows contract (3 / 5 / 8), labels and validation come from FormField, and resize defaults to vertical.

Sizes — rows contract + token minimum height

sm — rows=3, min-height --space-16, --text-body-sm.

md — rows=5, min-height --space-24, --text-body-md.

lg — rows=8, min-height --textarea-min-height-lg.

Content & states

short content — single line in an sm field.

multiline — paragraphs keep the --text-body-md line-height rhythm.
