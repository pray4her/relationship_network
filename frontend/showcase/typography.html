Applicable state matrix — text roles × context

Normal

Each role owns its normal semantic color: headings use --foreground, body roles use their body ink Tokens, and supporting roles use their dedicated muted hierarchy.

Muted · inverse · disabled

.text--muted uses --muted-foreground; inverse uses --on-dark; disabled preserves the role color and applies --opacity-disabled.

Semantic feedback

Success, warning, destructive, and info use their base semantic Tokens on matching soft surfaces. The --*-foreground Tokens remain reserved for ink on solid semantic fills.

Responsive display hierarchy

Display and h1 switch to their compact font-size Tokens below the existing responsive breakpoint. No raw font size, weight, line-height, letter-spacing, or color is introduced. Roles without a letter-spacing Token leave the property unset so it remains normal rather than inventing a value.
