Responsive

Below 768px, .text--display and .text--h1 switch to the compact display tokens (--text-display-xl-compact / --text-display-lg-compact). The breakpoint is a literal value — plain CSS media queries cannot consume var() — following the documented precedent in design-system.html. Resize the viewport to see it.
