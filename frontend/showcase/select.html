Component

Select

A WAI-ARIA listbox: the trigger shares the Input family's field chrome, the menu floats on --popover with the system's only shadow. Focus stays on the trigger and the menu navigates through aria-activedescendant — Arrow keys move, Enter/Space select, Escape closes, Home/End jump to the ends. The script below is the keyboard layer only; every visual comes from select.css tokens.
