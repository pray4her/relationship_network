Navigation item states

Forced with .is-* classes for the static showcase; live items use the pseudo-classes and aria-current.

  • Default — muted ink on canvas
  • Hover — --accent fill
  • Pressed — --surface-cream-strong
  • Current — selected pair, inline-start edge
  • Focus-visible — --ring-focus ring
  • Current + focus — edge under the ring
  • Disabled — --opacity-disabled
  • With badge — composed .badge 12

Default runs --muted-foreground (the rail reads quieter than the top nav); hover fills --accent; pressed holds --surface-cream-strong; current is the semantic selection pair rotated to the inline-start edge, driven by aria-current="page", never a parallel class. The icon inherits every state color through currentColor.
