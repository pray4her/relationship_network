Component

Avatar

An identity glyph in three variants — image, initials fallback, generic fallback — across five sizes, with an optional presence dot. Non-interactive by default; .avatar--interactive turns an <a> or <button> root into a profile link or picker target with native keyboard support. Static state classes (.is-hover, .is-focus-visible) mirror the real pseudo-classes so this page can render them without interaction. Every value is a tokens.css reference.

Interactive states

profile link — default / hover / focus-visible

picker button — same classes on a <button> root, with status

Keyboard is native to the chosen root — Tab focuses, Enter (and Space on <button>) activates; the component adds no JS. Hover lifts with the one sanctioned shadow (--shadow-subtle), focus-visible paints the shared --ring-focus ring at --ring-width, and the transition is --duration-fast --ease-standard, killed under prefers-reduced-motion. Variant and interactive modifiers compose on the same root (avatar avatar--lg avatar--initials avatar--interactive) — no wrapper needed.

Accessibility patterns

informative — role="img" + aria-label; inner img is alt=""

KJ

decorative — aria-hidden; the adjacent name already speaks

Ada Lovelace GH Grace Hopper

standalone meaningful image — real alt text, no role/label on root

Three labeling recipes, one visual result. Informative avatars put the name on the root (role="img" aria-label="…") so the inner <img> keeps alt="" and initials/icon add nothing — role="img" makes children presentational. Decorative avatars (aria-hidden="true") never duplicate a name already visible as text. When the photo itself is the content, plain alt carries the meaning.
