SearchField

Input with a search dialect, not a new language: the chrome, sizes, states, and clear control are Input's own classes (.input-wrap, .input, .input__icon, .input__clear). This component adds only the shortcut hint and the loading spinner. Empty fields show the hint; typing swaps it for the clear button; loading swaps both for the spinner.

The slot lifecycle is pure CSS: :placeholder-shown toggles hint vs clear, .search-field--loading overrides both with the spinner. The clear control is a real <button aria-label="Clear search"> — Tab to it and the token focus ring appears.
